ORIGIN
------

These are the 12 standard chess pieces of the "Cburnett" set, downloaded from
Wikimedia Commons, category "SVG chess pieces/Standard transparent".

This is the set Wikipedia uses to illustrate chess articles, and the set the
lichess.org source tree ships as its default piece set
(https://github.com/lichess-org/lila/tree/master/public/piece/cburnett; checked
2026-08-31, where an open proposal to change that default exists as lila#15365).

Nothing here came from a commercial chess platform. Every file was fetched from
Wikimedia Commons at the revision recorded below, and the sha1 of every download
was computed locally and compared against the sha1 Commons reports for that file.

THE 12 FILES
------------

Each permalink is pinned to the exact revision whose license block and author
line were read. The sha1 is of the SVG file as committed here; it was computed
from the downloaded bytes and matches the value Commons reports.

Those values hold as long as git does not rewrite the bytes between the commit
and the working tree (ADR-039). .gitattributes in the repository root keeps
end-of-line conversion off for assets/pieces/svg/*.svg. With core.autocrlf=true -
the usual setting on Windows - a checkout would turn LF into CRLF and every sha1
below would differ. Deleting that line silently invalidates this whole section,
and nothing in .gitattributes points back here to say so; tests/test_assets.py
checks the values and the line they depend on.

THE PNG FILES ARE GENERATED, THE ARTWORK IS NOT OURS
----------------------------------------------------

    assets/pieces/svg/       the 12 originals, byte for byte as downloaded
    assets/pieces/png/80/    rasterized at 80 x 80
    assets/pieces/png/32/    rasterized at 32 x 32

The PNG files are rasterizations of the SVG files sitting next to them, produced
by tools/rasterize_pieces.py using pygame 2.6.1 (SDL_image 2.0.5, nanosvg). They
are derivative works of the SVGs and carry the same license and the same
attribution; the rasterization itself adds no artistic contribution.

The SVG originals are kept because they are the source and the PNGs are the
generated artefact. They are also what the web client uses in phase 4.
