================================================================================

This file is ours. LICENSE.txt next to it is not.

WHY THEY ARE SEPARATE
---------------------

LICENSE.txt is a third-party document, written by Bitstream and Tavmjong Bah. It
is copied here byte for byte, and nothing of ours is added to it. A sentence about
this repository, inserted into someone else's license, would produce a document
that reads as a license but is not only one - and whoever copies it into their own
project next year would carry our sentence along as if it were part of the terms.
The sha256 values below are in the same position: they are our claims, not theirs.

assets/pieces/LICENSE.txt is the opposite case, which is why it is handled the
opposite way. That file is our document that quotes a third-party license; the
notice about .gitattributes belongs inside it, because the document is ours to
write.

WHAT THESE SHA256 VALUES DEPEND ON
----------------------------------

They hold as long as git does not rewrite the bytes between the commit and the
working tree (ADR-039). .gitattributes in the repository root covers that:

    assets/fonts/LICENSE.txt   -text      no end-of-line conversion
    *.ttf                      binary     no conversion, not treated as text

Deleting either line silently makes the values above wrong, and nothing in
.gitattributes points back here to say so. tests/test_assets.py checks both the
values and the lines they depend on.
